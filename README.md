# 🎮 Hangman Game Project

A fun and interactive web-based Hangman Game developed using Python and Flask as part of the CodeAlpha Python Programming Internship.

## 📌 About the Project

Hangman is a word-guessing game where players try to guess a hidden word one letter at a time using the given hint.

Players have a maximum of 6 incorrect guesses to identify the secret word before the game ends.

## ✨ Features

- 30 predefined words with hints.
- Interactive letter-selection keyboard.
- Maximum of 6 incorrect guesses.
- Visual Hangman drawing.
- Score tracking.
- New Game option.
- Responsive and attractive user interface.
- Win and lose messages.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/sindhu-m2/Hangman-Game-Project.git
```

2. Open the project folder:

```bash
cd Hangman-Game-Project
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
